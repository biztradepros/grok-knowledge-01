# 풀 수 있는 LOT 만들기

다른 개발자나 AI 에게 이 연구를 넘길 때 쓰는 안내서다.

## 1. ULTRA-001 이 오래 걸린 이유

| 원인 | 실제로 일어난 일 |
|---|---|
| 한 턴에 산출물이 너무 많았다 | 필수 절 20개와 공격 사례 14개(A–N)에, 규칙 버전·모순·exactly-once·권한·최소 상태·컴포넌트 제거·상태 기계·복구표·자산 매핑까지 요구됐다. 결과 문서는 1,234줄이다. |
| 절끼리 맞물린다 | 불변식 하나를 고치면 반례표, 상태 기계, 복구표, 반환 블록을 다시 맞춰야 한다. 비용이 "절 수 × 교차 확인"으로 커진다. |
| 끝나는 조건이 없었다 | "불가능 경계를 찾아라", "공격하라", "제거해 보라"에는 멈출 지점이 없다. 확신이 설 때까지 계속 확인하게 된다. |
| 돌려 볼 시험이 없었다 | 전부 종이 위 추론이었다. 확인 방법이 "머릿속에서 다시 유도하기"뿐이라, 코드를 한 번 돌리면 끝날 확인을 생각으로 했다. |
| 최대 추론 모드 | 요청 자체가 "MAXIMUM REASONING / ONE HARD PROBLEM" 이었다. 설계상 오래 걸리는 조합이다. |

중간에 끊으면 커밋하기 전의 작업은 사라진다. 작은 LOT 은 끝날 때마다 커밋한다.

비교: 같은 연구에서 나온 작은 질문 하나(CL2-APPLIED-RD-001)는 파일 3개, 자가시험 1개로 끝났고 결과가 PASS/FAIL 로 나왔다.

## 2. 풀 수 있는 LOT 의 조건

1. **질문 하나.** 한 문장이고 예/아니오로 끝난다.
2. **입력을 준다.** 필드 목록, 예시 데이터, 참고 파일 경로.
3. **산출물 경로를 정한다.** 예: `research/cl2/xxx.py`
4. **합격 조건을 실행 가능한 시험으로 쓴다.** 명령 하나, 결과는 PASS 또는 FAIL.
5. **하지 말 것을 적는다.**
6. **시간 상한을 둔다.** 예: 30분. 상한에 닿으면 멈추고 그때까지의 결과와 막힌 이유를 보고한다.
7. **새로 발견한 문제는 BACKLOG 로만 적는다.** 그 자리에서 풀지 않는다.

### 템플릿

```
LOT: <id>
질문: <한 문장>
입력: <필드/예시/파일>
산출물: <경로>
합격: <명령> 실행 시 PASS
금지: <목록>
시간 상한: 30분 — 넘으면 멈추고 보고
반환: PROBLEM / SOLUTION / PASS|FAIL / BACKLOG(≤3) / NEXT(1)
```

## 3. ULTRA-001 을 다시 쪼갠 작업 (각각 30분 안팎)

| # | 질문 | 산출물 | 합격 조건 | 상태 |
|---|---|---|---|---|
| 1 | 결과가 어떤 입력을 소비했는지 나중에 증명할 수 있나? | JRR v0.1 스키마 + 검사기 | T1 장면에서 B = `STALE_DEPENDENCY` | **완료 — WORKS** ([CL2-APPLIED-RD-001](CL2-APPLIED-RD-001.md)) |
| 2 | 저장된 기록이 작성 후 수정되었는지 알아낼 수 있나? | 기록 해시 규칙 + 검사기 | B 의 `consumes` 를 한 글자 바꾸면 FAIL | BACKLOG — DREAM 개발을 막고 있지 않아 착공하지 않음 |
| 3 | `approved` 라벨을 사람이 붙였는지 기계가 확인할 수 있나? | `labeled` 이벤트의 sender 를 보는 워크플로 **초안** (병합하지 않음) | 시험용 이벤트 데이터에서 AI 계정 → 거부, 사람 계정 → 통과 | 먼저 확인 필요: 각 AI 가 GitHub 에 어떤 계정으로 쓰는지 |
| 4 | 규칙이 바뀐 뒤에도 옛 판정을 그대로 재현할 수 있나? | `rule_version` 별 판정 함수 2개 + 재생 시험 | v1 에서 받은 기록이 v2 를 켠 뒤 재생해도 v1 판정을 유지 | 대기 |
| 5 | T1 이 모든 이벤트 순서에서 잡히나? | 작은 전수 검사기 (persona 2, step 2) | PRD-001 규칙에서는 T1 이 발견되고, JRR 규칙에서는 발견되지 않음 | 대기 |

각 작업은 앞 작업의 결과만 입력으로 받는다. 순서대로 하나씩 넘기면 된다.
